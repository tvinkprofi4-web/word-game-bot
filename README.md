# Roblox Word Game Auto-Typer

Скрипт для игры «Игра в Слова» в Roblox (поддерживает Xeno и другие экзекуторы).

## Быстрый запуск (Loadstring):
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/tvinkprofi4-web/word-game-bot/main/main.lua"))()
```

## Особенности:
- Поддержка 1, 2 и 3 букв раунда (например: `[М] [Й]`, `[Н] [Й]`, `[П] [Р] [О]`).
- 100% валидные словарные существительные (именительный падеж, единственное число).
- Запоминает использованные слова (не повторяется).
- Автоматически отрезает первую букву, чтобы не было дублей (`ААКУЛА`).
- Бинд: **`Q`** (или `F2`) для ответа, **`Ctrl + R`** для сброса истории использованных слов.
